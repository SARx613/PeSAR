PeSAR — API

Backend — Taux de change EUR → ARS (Western Union)
Actualisé automatiquement toutes les 15 min via GitHub Actions.

Endpoints

GET /api/latest-rate

Retourne le dernier taux EUR → ARS enregistré dans Redis.

200 OK 
{
  "ok": true,
  "rate": 1234.56,
  "timestamp": "2026-05-06T15:00:00.000Z"
}
GET /api/rate-history

Retourne l'historique complet des taux stockés en Redis (jusqu'à 96 points, soit ~24h à intervalles de 15 min).

200 OK 
{
  "ok": true,
  "history": [
    { "rate": 1230.00, "timestamp": "2026-05-05T15:00:00.000Z" },
    { "rate": 1234.56, "timestamp": "2026-05-06T15:00:00.000Z" }
  ]
}
POST /api/register-token

Enregistre un token Expo Push Notifications pour recevoir les mises à jour silencieuses de taux.

200 OK 
{
  "ok": true
}
GET /api/scrape-rate 🔒 Protégé

Déclenche le scraping du taux Western Union, stocke le résultat dans Redis et envoie une notification silencieuse à tous les tokens enregistrés.

Nécessite le header Authorization: Bearer <CRON_SECRET>.

200 OK 
{
  "ok": true,
  "rate": 1234.56,
  "timestamp": "2026-05-06T15:00:00.000Z",
  "source": "western_union_graphql"
}
💡 Le scraping utilise l'API GraphQL publique de Western Union comme source principale, avec un fallback vers dolarapi.com en cas d'échec. Le job GitHub Actions tourne toutes les 15 minutes.
